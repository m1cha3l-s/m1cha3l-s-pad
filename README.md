# m1cha3l's pad

My take on a macropad but with comfort added. Featuring 5x custom mapable MX-Style switches, 1x Rotary encoder and a 0.91 inch OLED desplay.

The pad runs QMK Firmware with VIA on a Seeed XIAO RP2040. VIA Allows easy customization without the need to reflash firmware.

# IMPORTANT NOTES

To balance the weight you HAVE to put few washers in the bottom part and secure them with hot glue.

You first have to put the switches in the top part, then solder the OLED to the PCB, then you can solder the switches and click them into the bottom part of the case
